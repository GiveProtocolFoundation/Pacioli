# Internal engineering notes

This directory holds historical implementation plans, status reports, and
design notes that informed earlier phases of Pacioli's development. They are
preserved for context but **are not user-facing documentation**.

For user, developer, or API documentation, see the [pacioli-docs
repository](https://github.com/GiveProtocolFoundation/pacioli-docs) or
[docs.pacioli.io](https://docs.pacioli.io).

Files here may be stale, partially superseded, or describe work that has
since shipped. Treat them as snapshots, not authoritative references.
